## 一、需立即处理（2 项）

### P1 · Agent.vue 定时器修复引入了语法错误（编译必挂）🔴
- **位置**：`frontend/src/views/monitor/Agent.vue` 第 298、303 行
- **现状**：
  ```js
  let refreshTimer: number | null = null          // ← TypeScript 类型标注
  refreshTimer = setInterval(load, 30000) as unknown as number   // ← TS 断言
  ```
  但该文件是 `<script setup>`（第 107 行，**无 `lang="ts"`**），整个前端项目均为 JS。Vite/esbuild 会把这两行当 JS 解析，直接 SyntaxError——Agent 页面无法编译，dev server 报错覆盖层、`npm run build` 也会失败。
- **与文档矛盾**：修复文档第五节声称「Agent.vue 经 vite 编译均 200」，与当前源码不符（可能该改动发生在验证之后，或验证时点有误）。
- **修法（1 分钟）**：改为
  ```js
  let refreshTimer = null
  refreshTimer = setInterval(load, 30000)
  ```
  改完建议真的跑一次 `npm run build` 再写验证记录。

### P2 · Incident.vue 双重解包只修了一半，相似案例面板依然恒空 🟠
- **位置**：`frontend/src/views/alert/Incident.vue` 第 331-332 行
- **现状**：
  ```js
  aiData.value = rc || null                                  // ✅ 已修
  similar.value = { cases: (sim.data?.cases) || [], matchType: sim.data?.matchType || null }   // ❌ 仍是双重解包
  ```
- **依据**：后端 `KbCaseController.findSimilarCases()` 返回 `Result.ok(Map)`，Map 顶层键就是 `incidentId/seedText/matchType/cases`（见 `SimilarCaseServiceImpl` 90-93 行）；axios 拦截器解包后 `sim` 即该 Map 本体，`sim.data` 恒为 undefined → 相似案例列表永远为空。
- **与文档矛盾**：文档第 30-33 行声称该问题已修复且「与 runReport() 写法已一致」，实际只修了 `aiData` 一行。
- **修法**：`similar.value = { cases: sim?.cases || [], matchType: sim?.matchType || null }`
